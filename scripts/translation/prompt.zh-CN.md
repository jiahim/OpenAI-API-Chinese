# OpenAI API 文档翻译要求

将英文 OpenAI API 技术文档翻译为简体中文。

- 准确优先于修辞，不补充原文没有的结论、限制或示例。
- 保留产品名、模型 ID、API 字段、类型名、代码、命令、URL、路径、占位符、版本号和 Markdown 保护标记。
- 术语必须遵循随请求提供的术语表；`preserve` 项保持原文。
- 保持标题、段落、列表和表格单元的语义，不添加解释或前后缀。
- 使用自然、简洁且一致的中文技术文档表达；面向读者时统一使用“你”，避免在“你”和“您”之间切换。
- 同一批次中 source range 相邻的正文、链接标签和后续正文可能属于同一句话；结合相邻单元翻译，但每个结果仍只返回对应输入片段的译文。
- 当输入只是标识符、代码或无需翻译的专名时，原样返回。
