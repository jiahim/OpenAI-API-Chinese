# Responses 概览

> 如需查看完整文档索引，请参阅 [llms.txt](/llms.txt)。在页面 URL 末尾添加 `.md` 即可获取文档页面的 Markdown 版本。

OpenAI 用于生成模型响应的最先进接口。支持
文本和图像输入，并输出文本。基于前一次响应的输出作为输入，
创建与模型的有状态交互。通过内置工具扩展模型能力，
包括 文件搜索、网页搜索、
计算机使用等。通过函数调用让模型访问外部系统和数据。
使用函数调用即可让模型访问外部系统和数据。
