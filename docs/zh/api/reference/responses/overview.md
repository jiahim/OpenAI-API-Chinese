# Responses 概览

> 完整的文档索引，请参阅 [llms.txt](/llms.txt)。文档页面的 Markdown 版本可通过在页面 URL 后追加 `.md` 来获取。

OpenAI最先进的模型响应生成接口。支持
文本和图像输入，以及文本输出。利用前一次响应的输出作为输入，
与模型进行有状态的交互。通过内置工具扩展
模型能力，如文件搜索、网页搜索、
计算机使用等。允许模型访问外部系统和数据，
使用函数调用。
