# 管理概述

> 完整的文档索引请参见 [llms.txt](/llms.txt)。可通过在页面 URL 末尾追加 `.md` 来获取文档页面的 Markdown 版本。

使用 Administration API 管理组织资源，例如用户、邀请、项目、API 密钥和审计日志。
要访问这些端点， [请创建一个 Admin API 密钥](https://platform.openai.com/settings/organization/admin-keys)。Admin API 密钥不能用于非管理类端点。
