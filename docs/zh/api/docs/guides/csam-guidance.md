### 规模保障措施

合适的控制与安全保障取决于产品、其开发阶段
和成熟度、其用户与功能、所运营的地区，以及其
可用资源。

风险敞口较大的产品——例如支持以下功能的产品：
直播、图像生成或编辑、文件存储或私密连接——
应考虑实施并加强以下防护措施：

- 在上线前以及每当高风险功能发生变化时进行产品风险评估。
  参见。
- 与服务相适应的分层检测，可能包括哈希匹配、
  图像或视频分类器、文本信号、关键词检测以及 URL 拦截。
- 对高置信度或高严重性信号进行人工复核，使用能够
  保护审核人员身心健康并限制其不必要接触有害
  内容的工具。
- 速率限制、账户控制和滥用监控，使重复滥用行为
  更难发生。
- 定期进行测试和衡量，以便你发现差距、跟踪结果并
  改进你的控制措施。

这些建议只是一个起点，并非法律建议或通用的
行业审慎标准。请结合你的服务、风险状况以及适用法律进行调整。
