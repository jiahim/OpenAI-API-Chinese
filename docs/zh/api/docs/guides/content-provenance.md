## 内容来源核查

内容溯源检查支持针对以下信号的文件：

| 信号                   | 适用范围       | 检查内容                                   |
| ------------------------ | ---------------- | ------------------------------------------------ |
| C2PA Content Credentials | 图像           | 带有颁发者和 AI 使用详情的签名元数据   |
| SynthID                  | 图像和音频 | 直接嵌入受支持媒体中的水印 |

C2PA 元数据可提供有关文件来源的更多上下文。编辑、转换，
或共享文件可能会移除其元数据。SynthID 水印是
图像或音频本身的一部分，可能在某些转换后仍然存在。

该 API 会检查受支持的 OpenAI 信号。它并非通用的人工智能
检测器，也无法识别由每个 AI 系统生成的内容。可见
水印和标签与该
API 检查的来源信号是分开的。

## 验证文件

通过 该公司 SDK 的 `file` 字段上传图片或音频文件。OpenAI SDK 会构建
多部分请求，并从环境变量中读取你的 API 密钥： `OPENAI_API_KEY`
验证图片：

```javascript
import { createReadStream } from "node:fs";
import OpenAI, { toStreamingFile } from "openai";

const client = new OpenAI();

const result = await client.contentProvenanceChecks.create({
  file: toStreamingFile(createReadStream("myimage.png"), "myimage.png", {
    type: "image/png",
  }),
});
```


```go
package main

import (
	"context"
	"fmt"
	"os"

	"github.com/openai/openai-go/v3"
)

func main() {
	client := openai.NewClient()

	image, err := os.Open("./example.png")
	if err != nil {
		panic(err)
	}
	defer image.Close()

	result, err := client.ContentProvenanceChecks.New(
		context.Background(),
		openai.ContentProvenanceCheckNewParams{
			File: openai.File(image, "example.png", "image/png"),
		},
	)
	if err != nil {
		panic(err)
	}

	fmt.Println(result)
}
```

响应包含已完成的结果。例如，图片会返回：

```json
{
  "object": "content_provenance_check",
  "created_at": 1778000000,
  "results": [
    {
      "type": "c2pa",
      "outcome": "detected",
      "validation_state": "trusted",
      "issuer": "OpenAI OpCo, LLC",
      "model": "gpt-image",
      "generated_at": "2026-07-27T18:34:12Z"

      "model": null,
```

该 `object` 字段用于标识该响应 `created_at` 是检查的

SynthID 结果。API 会省略不适用的检查，而不是返回
`not_detected`.

API 在返回前会完成验证。你无需创建
后台任务、轮询其他端点，或将文件上传到 Files API。

如果请求失败，请检查 HTTP 状态码和 `error.code` 时可用。一个
格式错误、不受支持或被屏蔽的文件会返回 `400`；没有访问权限的组织会收到
；超过速率限制的请求会返回 `404`。 `429`. 仅重试
瞬时失败，例如限流或服务端错误。有关一般指导，
请参阅 [API 错误代码](https://developers.openai.com/api/docs/guides/error-codes).

## 理解验证结果

请独立阅读每条适用的条目 `results` 。图像结果包含
C2PA 和 SynthID 条目，而音频结果包含 SynthID 条目。
响应不包含顶层 `outcome`.

### C2PA results

C2PA 结果描述图像的 Content Credentials 状态：

```json
{
  "type": "c2pa",
  "outcome": "detected",
  "validation_state": "trusted",
  "issuer": "OpenAI OpCo, LLC",
  "model": "gpt-image",
  "generated_at": "2026-07-27T18:34:12Z"
}
```

各字段的使用方式如下：

- `outcome` 表示是否使用了 OpenAI 签发的 AI 生成凭证
  `detected` 或 `not_detected`.
- `validation_state` 表示清单是否 `trusted`, `valid`,
  `invalid`，或 `not_present`.
- `issuer` 在可用时标识清单的签发者。
- `model` 在可用时标识生成该内容的模型。
- `generated_at` 在该信息可用时标识内容的生成时间
  。

结果仅在 `detected` 清单将 `trusted` 标识为 `valid` 发布者并包含 AI 生成操作时才有效。第三方
OpenAI 作为其发布者，并包含一个 AI 生成操作。第三方
清单、不包含 AI 生成操作的清单、 `invalid` 清单，或
一个 `not_present` 清单会产生 `not_detected`。 `issuer` 和
`validation_state` 仍然可以描述清单，即使结果为
`not_detected`.

不要将 `invalid` 清单视为可靠的可追溯性证据。
`not_present` 结果表示该图像没有可用的 C2PA 清单。

### SynthID results

SynthID 结果用于描述验证器是否在图像或音频文件中检测到受支持的水印
：

```json
{
  "type": "synthid",
  "outcome": "detected",
  "model": null,
  "generated_at": null
}
```

结果为 `detected` 表示该文件包含已识别的水印。结果为
表示 `not_detected` 验证器未检测到该水印。这并
不能排除内容是 AI 生成或 AI 修改的可能。 `model` 和
`generated_at` 在可用时提供生成模型和生成时间；
其中任一字段可为 `null`.

## 支持的上传

默认情况下，API 支持以下文件格式：

- **图像：** PNG、JPEG 和 WebP。
- **音频：** MP3、Opus、AAC、FLAC、WAV 和 PCM。

将每个上传的文件限制为 50 MiB。音频解码后时长必须不超过 60 秒，
并设置上传。

部分的媒体类型。例如，使用 `file` 表示 PNG 图像， `image/png` 或使用
表示 Opus 音频。不要另外添加 `audio/ogg` 字段，也不要手动设置请求头。 `type` 选项
会设置请求内容类型和多部分边界。每次请求发送一个文件。 `multipart/form-data` request header. The `curl` `-F` option
sets the request content type and multipart boundary. Send one file per request.

## 速率限制

严格的速率限制有助于保护 API 免遭滥用。组织可以
[申请更高的限制](https://openai.com/form/content-provenance-api/)，以及
OpenAI 会逐案审核每个申请。

如果 API 返回 `429 rate_limit_exceeded`，降低请求频率并
遵守 `Retry-After` 响应头（如果存在）。参见
[速率限制](https://developers.openai.com/api/docs/guides/rate-limits) 以获取通用的重试指导。

## 负责任地使用验证结果

将验证结果作为更广泛审查流程中的证据：

- 将 `detected` 视为特定受支持信号的证据，而非该文件的完整
  历史记录。
- 将 `not_detected` 视为未检测到证据，而非证明该
  内容是人工创作的或未使用 OpenAI 生成。
- 在将图像归属于特定提供方之前，请检查 C2PA 颁发者。
- 尽可能验证原始文件。压缩、裁剪、截屏、
  元数据删除以及格式转换都可能削弱或抹除信号。
- 考虑原始产品、模型、文件格式和创建日期。
  并非所有 OpenAI 生成的内容都包含受支持的信号。
- 在高风险工作流中，将自动决策与人工审核结合使用。
- 不要使用重复查询来逆向工程、移除或规避水印。
- 不要从验证
  结果中推断提示词、账户或个人创建者。
