# 红队测试

> 有关完整文档索引，请参阅 [llms.txt](/llms.txt)。在页面URL后追加 `.md` 即可获取文档页面的Markdown版本。

红队测试通过对抗性测试用例，帮助在部署前发现不安全、不稳固或违反策略的行为。它通过关注普通质量测试可能无法揭示的滥用案例、故障模式和高风险交互来补充评估。

**重要：** 仅提交你拥有或明确获准测试的 OpenAI 红队代码或其他
  资产。未经 OpenAI 明确书面许可，请勿使用红
  队测试来分析或报告开源或任何第三方
  代码中的漏洞，除非获得 OpenAI 的明确书面许可。

## 使用 Promptfoo 进行开源红队测试

[Promptfoo](https://github.com/promptfoo/promptfoo) 是一个用于评估提示词、智能体和 AI 应用的开源框架。其红队工作流可帮助你生成对抗性测试用例、检查目标行为，并利用结果改进你的系统。

要了解更广泛的开源方法论，请参阅 Promptfoo 的 [LLM 红队指南](https://www.promptfoo.dev/docs/red-team/).

## 企业可用性

OpenAI Red Teaming 适用于需要托管式红队测试 AI 应用程序和智能体的企业客户。企业工作流可以比本地独立的工作流支持更广泛的协调、审查和报告需求。

## 红队测试与评估

使用 [评估](https://developers.openai.com/api/docs/guides/evals) 来衡量 AI 系统是否按预期运行。使用红队测试来探测该系统在面对对抗性、滥用性或意外输入时的行为。成熟的评估项目通常会同时采用这两种方法。
