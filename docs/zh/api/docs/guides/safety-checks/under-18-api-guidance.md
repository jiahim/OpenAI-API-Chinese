# 18 岁以下 API 指南

> 如需完整文档索引，请参阅 [llms.txt](/llms.txt)。可通过在页面 URL 末尾追加 `.md` 来获取文档页面的 Markdown 版本。

未成年人在线上和线下都有独特的需求，因此开发者在使用我们的 API 为未成年人（18 岁以下）提供服务时，应当实施额外的安全保障措施。这些措施是对我们的 [使用政策](https://openai.com/policies/usage-policies/) 和 [条款与条件](https://openai.com/policies/services-agreement/).

**监管标准**

面向未成年人提供服务的组织必须遵守所有适用的儿童保护、安全和隐私法律，包括《儿童在线隐私保护法》（COPPA）。在未先在我们的 API 中启用零数据保留之前，你不得使用 OpenAI 服务处理任何 13 岁以下儿童或低于适用数字同意年龄的儿童的个人数据。你应全权负责确保你以及你的用户在遵守适用法律的前提下使用 OpenAI 服务。

**安全标准**

面向未成年人提供服务的组织必须采取合理措施，确保通过 API 向未成年人提供的内容是安全且适合其年龄的，符合我们使用政策中“保护未成年人安全”的要求。这可能包括但不限于：

1. 向未成年人提供与年龄相符的 AI 工具说明以及如何负责任地使用这些工具。
2. 实施与年龄相符的内容过滤器，以应对潜在的敏感内容。
3. 实施合理的监控和报告机制，包括针对高风险交互的升级路径。
4. 在用例需要或适合的情况下，使用年龄核验系统来确保只有预期用户能够访问该产品。

**最佳实践**

面向未成年人的组织在与我们的 API 交互时应遵循以下最佳实践：

- 在处理未成年人的数据和交互时务必格外谨慎，并在识别出对年轻用户的风险时采取适当行动。
- 利用 OpenAI 可能提供的可用安全工具并遵循其技术安全措施，这些措施旨在为特定用户群体（包括未成年人）定制产品体验。
- 使用 OpenAI 最新的旗舰模型，这些模型融合了最新的安全防护措施，尤其是在为未成年人构建体验时。

OpenAI 保留对各组织遵守本政策情况进行审计的权利。未能证明合规性的客户可能会收到警告，对于屡次违规或严重违规的情况，可能会被暂停或终止 API 访问权限。
