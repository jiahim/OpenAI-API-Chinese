# 18 岁以下 API 使用指南

> 有关完整的文档索引，请参阅 [llms.txt](/llms.txt)。文档页面的 Markdown 版本可通过在页面 URL 后追加 `.md` 来获取。

年轻人在线上和线下都有独特的需求，因此开发者在使用我们的API为未成年人（18岁以下）提供服务时，应实施额外的保障措施。这些措施是我们的 [使用政策](https://openai.com/policies/usage-policies/) 和 [条款与条件](https://openai.com/policies/services-agreement/).

**监管标准**

服务未成年人的组织必须遵守所有适用的儿童保护、安全和隐私法律，包括《儿童在线隐私保护法》（COPPA）。在未首先在我们的API中实施零数据保留的情况下，你不应使用OpenAI服务处理13岁以下或适用的数字同意年龄以下儿童的任何个人数据。你全权负责确保你和你的用户遵守适用法律使用OpenAI服务。

**安全标准**

服务未成年人的组织必须采取合理步骤，确保他们通过API向未成年人提供的内容是安全的且适合年龄，符合我们“保护未成年人安全”的使用政策。这可能包括但不限于：

1. 向未成年人提供适合其年龄的关于 AI 工具及如何负责任地使用它们的说明。
2. 实施适合年龄的内容过滤器，以处理可能敏感的内容。
3. 实施合理的监控和报告机制，包括高风险互动的升级路径。
4. 在需要或适合你的使用场景时，使用年龄验证系统，确保只有目标用户能够访问产品。

**最佳实践**

服务未成年人的组织在与我们的 API 交互时应遵循以下最佳实践：

- 处理未成年人的数据与互动时需格外谨慎，并在发现对年轻用户存在风险时采取适当行动。
- 利用可用的安全工具，并遵循OpenAI可能提供的技术安全措施，这些措施旨在为特定用户群体（包括未成年人）定制产品体验。
- 使用OpenAI最新的旗舰模型，这些模型融合了最新的安全保护，特别是在为未成年人构建体验时。

OpenAI 保留对组织遵守本政策情况进行审计的权利。未通过合规证明的客户可能会收到警告，若存在多次或严重违规行为，可能会被暂停或终止API访问权限。
