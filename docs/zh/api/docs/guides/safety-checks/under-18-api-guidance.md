# 未满 18 岁相关指引

> 有关完整文档索引，请参阅 [llms.txt](/llms.txt)。在页面 URL 末尾追加 `.md` 即可获取文档页面的 Markdown 版本。

年轻人在线上和线下都有独特需求，因此开发者在使用我们的 API 服务未成年用户（18 岁以下）时，应当实施额外的安全防护措施。这些措施是对我们的 [使用政策](https://openai.com/policies/usage-policies/) 以及 [条款和条件](https://openai.com/policies/services-agreement/).

## 监管标准

面向未成年人的组织必须遵守所有适用的儿童保护、安全和隐私法律，包括《儿童在线隐私保护法》(COPPA)。在未先在我们的 API 中实现零数据保留之前，你不应使用 OpenAI 服务处理任何 13 岁以下儿童或适用数字同意年龄以下的儿童的个人数据。你应独自负责确保你及你的用户在使用 OpenAI 服务时遵守适用法律。

## 安全标准

面向未成年人提供服务的企业必须采取合理措施，确保通过 API 向未成年人提供的内容安全且符合其年龄要求，遵循我们“保护未成年人安全”的使用政策。此类措施可能包括但不限于：

1. 向未成年人提供适合其年龄的 AI 工具披露，并说明如何负责任地使用这些工具。
2. 实施适合年龄的内容过滤器，以应对潜在的敏感内容。
3. 实施合理的监控和报告机制，包括针对高风险交互的升级上报路径。
4. 在适用或对你的用例合适的情况下，使用年龄验证系统，确保只有目标用户能够访问该产品。

## 最佳实践

面向未成年人的组织在与我们 API 交互时，应遵循以下最佳实践：

- 在处理未成年人的数据和互动时应格外谨慎，并在识别到对年轻用户的风险时采取适当行动。
- 利用 OpenAI 可能提供的安全工具，并遵循其技术安全措施，这些措施旨在为包括未成年人在内的特定用户群体定制产品体验。
- 使用 OpenAI 最新的旗舰模型，这些模型融合了最新的安全防护措施，尤其是在为未成年人构建体验时。

OpenAI 保留对各组织进行合规审计的权利。未能证明合规性的客户可能会收到警告，并在反复或严重违规的情况下，被暂停或终止其 API 访问权限。
