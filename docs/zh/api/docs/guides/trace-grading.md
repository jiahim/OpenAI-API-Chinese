# 追踪分级

> 有关完整的文档索引，请参阅 [llms.txt](/llms.txt)。各文档页面的 Markdown 版本可通过在页面 URL 后追加 `.md` 获取。

追踪分级是将结构化评分或标签分配给智能体的追踪——即决策、工具调用和推理步骤的端到端日志——以评估正确性、质量或是否符合预期。这些标注有助于识别智能体表现良好或出错的地方，从而能够有针对性地改进编排或行为。

追踪评估使用这些已分级的追踪来系统地评估智能体在众多示例中的表现，有助于基准测试变更、识别回归或验证改进。与黑盒评估不同，追踪评估提供更多数据，以便更好地理解智能体成功或失败的原因。

同时使用这两项功能来跟踪、分析和优化智能体群体的性能。

## 追踪入门

1. 在仪表盘中，导航到“日志”> [追踪](https://platform.openai.com/logs?api=traces).
1. 选择一个工作流。你会看到来自基于SDK的应用的追踪，以及来自现有 [智能体构建器](https://developers.openai.com/api/docs/guides/agent-builder) 在过渡期间的工作流。
1. 选择一个追踪来检查你的工作流。
1. 创建一个评分器，并运行它以根据评分标准对你的智能体的表现进行评分。

追踪分级是规模化识别错误的重要工具，这对于为你的AI应用构建韧性至关重要。在我们的 [食谱](https://developers.openai.com/cookbook/examples/evaluation/building_resilient_prompts_using_an_evaluation_flywheel).

## 使用运行评估追踪

1. 选择 **全部评分**。这会带你进入评估仪表盘。
1. 在评估仪表盘中，添加并编辑测试标准。
1. 添加一次运行以评估输出。你可以配置运行选项，如模型、日期范围和工具调用，以便在评估中获得更高的具体性。

详细了解你可以如何使用 evals [此处](https://developers.openai.com/api/docs/guides/evals).
