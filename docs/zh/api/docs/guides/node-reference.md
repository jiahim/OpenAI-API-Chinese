# 节点参考

[智能体 Builder](https://platform.openai.com/agent-builder) 是一个用于编排智能体工作流的可视化画布。工作流由控制顺序和流程的节点与连接组成。插入节点，然后配置并连接它们，以定义你希望智能体遵循的过程。

下面探索所有可用的节点。要了解更多，请阅读 [智能体 Builder 指南](https://developers.openai.com/api/docs/guides/agent-builder).

### 核心节点

从基础构建模块开始。所有工作流都有起始节点和智能体节点。

![核心节点](https://cdn.openai.com/API/docs/images/core-nodes2.png)

#### 开始

定义工作流的输入。对于聊天工作流中的用户输入，起始节点负责两件事：

- 将用户输入追加到对话历史中
- 提供 `input_as_text` 来表示此输入的文本内容

所有聊天起始节点都 `input_as_text` 作为输入变量。你也可以添加状态变量。

#### 智能体

定义指令、工具和模型配置，或附加评估。

保持每个 智能体 的职责范围明确。在我们的作业助手示例中，我们使用一个 智能体 来重写用户的查询，使其更具体、与知识库更相关。我们使用另一个 智能体 将查询分类为问答或事实查找，并使用另一个 智能体 来处理每种类型的问题。

像使用任何其他模型提示一样添加模型行为指令和用户消息。要从前一个步骤输出结果，你可以将其添加为上下文。

你可以根据需要设置任意数量的 智能体 节点。

#### 注意

对工作流留下评论和说明。与其他节点不同，注释不 _会_ 在流程中执行任何操作。它们只是为你和你的团队提供有用的说明。

### 工具节点

工具节点让你能够为你的智能体配备工具和外部服务。你可以检索数据、监控滥用行为，并连接到外部服务。

![工具节点](https://cdn.openai.com/API/docs/images/tool-nodes2.png)

#### 文件搜索

从你在 OpenAI 平台创建的向量存储中检索数据。按向量存储 ID 搜索，并添加模型应搜索内容的查询。你可以使用变量将之前节点的输出包含到 工作流 中。

参见 [文件搜索 文档](https://developers.openai.com/api/docs/guides/tools-file-search) 以设置向量存储并查看支持的文件类型。

如需使用 OpenAI 搜索托管存储之外的内容，请使用 [MCP](#mcp) 代替。

#### 护栏

设置输入监视器，以检测不需要的输入，例如个人身份信息（PII）、越狱提示、幻觉和其他滥用行为。

护栏默认为通过/失败模式，即它们测试前一个节点的输出，由你定义后续操作。当护栏检查失败时，我们建议要么结束工作流，要么返回上一步并提示安全使用。

#### MCP

调用第三方工具和服务。通过 OpenAI 连接器或第三方服务器连接，或添加你自己的服务器。在需要读取或搜索另一个应用（如 Gmail 或 Zapier）中数据的 工作流中，MCP 连接非常有用。

在 智能体 Builder 中浏览选项。要了解更多关于 MCP 的信息，请参阅 [连接器和 MCP 文档](https://developers.openai.com/api/docs/guides/tools-connectors-mcp).

### 逻辑节点

![逻辑节点](https://cdn.openai.com/API/docs/images/logic-nodes.png)

逻辑节点允许你编写自定义逻辑并定义控制流——例如，在自定义条件下循环，或在继续操作前请求用户批准。

#### If/else

添加条件逻辑。使用 [通用表达式语言](https://cel.dev/) （CEL）创建自定义表达式。用于定义如何处理已归入分类的输入。

例如，如果智能体将输入归类为问答，则将查询路由到智能体以获得直接答案。如果是开放式查询，则路由到查找相关事实的智能体。否则，结束该工作流。

#### 虽然

根据自定义条件循环。使用 [通用表达式语言](https://cel.dev/) (CEL) 创建自定义表达式。适用于检查某个条件是否仍然成立。

#### 人工审批

交由最终用户审批。适用于智能体起草工作并希望在发出前经过人工审核的工作流。

例如，设想一个代表你发送电子邮件的智能体工作流。你会在其中包含一个输出邮件组件的智能体节点，紧接着是一个人工审批节点。你可以将人工审批节点配置为询问：“你希望我发送这封电子邮件吗？”如果获得批准，则继续执行连接到 Gmail 的 MCP 节点。

### 数据节点

数据节点可让你在工作流中定义和操作数据。重塑输出或定义全局变量，以便在整个工作流中使用。

![数据节点](https://cdn.openai.com/API/docs/images/data-nodes.png)

#### 转换

重塑输出（例如，对象 → 数组）。有助于强制类型符合你的模式，或将输出重塑为智能体可读取和理解的形式。

#### 设置状态

定义全局变量，以便在整个工作流中使用。当智能体接收输入并输出你希望在整个工作流中使用的新内容时，这非常有用。你可以将该输出定义为新的全局变量。
