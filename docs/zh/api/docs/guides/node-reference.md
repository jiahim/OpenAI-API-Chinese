# 节点参考

[智能体 Builder](https://platform.openai.com/agent-builder) 是一个用于编排智能体工作流的可视化画布。工作流由节点和连接组成，用于控制顺序和流程。插入节点，然后配置并将它们连接起来，以定义你希望你的智能体遵循的流程。

OpenAI 正在弃用 智能体 Builder。现有用户可以在
  过渡期内继续使用，该产品计划于
  2026-11-30 停用。ChatKit 仍可使用。请参阅 [弃用
  页面](https://developers.openai.com/api/docs/deprecations#2026-06-03-agent-builder) 了解当前的
  时间表。

浏览下方所有可用节点。要了解更多信息，请阅读 [智能体 Builder 指南](https://developers.openai.com/api/docs/guides/agent-builder).

### 核心节点

从基础构建块开始。所有工作流都具有 start（开始）和 智能体（智能体）节点。

![核心节点](https://cdn.openai.com/API/docs/images/core-nodes2.png)

#### 开始

定义 工作流的输入。对于聊天 工作流中的用户输入，起始节点做两件事：

- 将用户输入追加到对话历史中
- 对外提供 `input_as_text` 以表示此输入的文本内容

所有聊天起始节点都拥有 `input_as_text` 作为输入变量。你也可以添加状态变量。

#### 智能体

定义指令、工具和模型配置，或附加评估。

保持每个智能体的职责范围清晰。在我们的作业助手示例中，我们使用一个智能体来改写用户的查询，使其更具体、更贴合知识库；使用另一个智能体将查询分类为问答类或事实查找类，再使用一个智能体来处理对应类型的问题。

像编写任何其他模型提示一样，添加模型行为指令和用户消息。若要接入上一步的输出，可以将其作为上下文添加。

你可以按需添加任意数量的智能体节点。

#### 注意

留下关于你的工作流的注释和说明。与其他节点不同，备注不会 _对_ 流程做任何操作。它们只是为你和你的团队提供的辅助说明。

### 工具节点

工具节点可让你为智能体配备工具和外部服务。你可以检索数据、监控滥用情况，并连接到外部服务。

![工具节点](https://cdn.openai.com/API/docs/images/tool-nodes2.png)

#### 文件搜索

从你在 OpenAI 平台中创建的向量存储中检索数据。按向量存储 ID 进行搜索，并添加查询以指定模型应搜索的内容。你可以使用变量来引入工作流中前置节点的输出。

请参阅 [文件搜索 文档](https://developers.openai.com/api/docs/guides/tools-file-search) 以设置向量存储并查看支持的文件类型。

如果需要在 OpenAI 的托管存储之外进行搜索，请使用 [MCP](#mcp) 。

#### 护栏

为不需要的输入设置输入监控，例如个人身份信息 (PII)、越狱、幻觉和其他误用情况。

护栏默认采用通过/不通过的方式，意味着它们会测试上一个节点的输出，你可以定义接下来发生什么。当护栏未通过时，我们建议要么结束工作流，要么返回上一步并提示安全使用。

#### MCP

调用第三方工具和服务。通过 OpenAI 连接器或第三方服务器进行连接，或添加你自己的服务器。在需要在其他应用（例如 Gmail 或 Zapier）中读取或搜索数据的 工作流 中，MCP 连接非常有用。

在 智能体 Builder 中浏览选项。要了解有关 MCP 的更多信息，请参阅 [连接器和 MCP 文档](https://developers.openai.com/api/docs/guides/tools-connectors-mcp).

### 逻辑节点

![logic nodes](https://cdn.openai.com/API/docs/images/logic-nodes.png)

Logic 节点让你可以编写自定义逻辑并定义控制流——例如，在自定义条件上进行循环，或者在继续操作前请求用户审批。

#### If/else

添加条件逻辑。使用 [Common Expression Language](https://cel.dev/) (CEL) 来创建自定义表达式。这对于定义如何处理已被归类的输入非常有用。

例如，如果 智能体 将输入归类为问答类，则将该查询路由到问答 智能体 以获得直接的答案。如果是开放式查询，则路由到负责查找相关事实的 智能体。否则，结束该 工作流。

#### 虽然

基于自定义条件循环。使用 [Common Expression Language](https://cel.dev/) (CEL) 创建自定义表达式。可用于检查某个条件是否仍然成立。

#### 人工审批

由最终用户进行审批。适用于以下智能体起草内容可在发出前由人工复核的智能体。

例如，可以想象一个由智能体代表你发送邮件的工作流。你会包含一个输出邮件小部件的智能体节点，随后紧接一个人工审批节点。可以将该人工审批节点配置为询问“是否要发送这封邮件？”，并在通过审批后继续执行连接到 Gmail 的 MCP 节点。

### 数据节点

数据节点可让你在 工作流 中定义和操作数据。可以重塑输出，或定义可在整个 工作流 中使用的全局变量。

![data nodes](https://cdn.openai.com/API/docs/images/data-nodes.png)

#### Transform

对输出进行整形（例如，对象 → 数组）。可用于强制类型以符合你的架构，或对输出进行整形以便智能体读取并理解为输入。

#### 设置状态

定义供整个工作流使用的全局变量。当某个智能体接收输入并输出新的内容，而这些内容需要在整个工作流中使用时，这个功能非常有用。你可以将该输出定义为一个新的全局变量。
