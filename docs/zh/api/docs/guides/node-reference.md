# Node reference

> 如需完整文档索引，请参阅 [llms.txt](/llms.txt).可通过在页面 URL 末尾追加 `.md` 来获取该页面的 Markdown 版本。

[智能体 Builder](https://platform.openai.com/agent-builder) 是一个用于编排智能体工作流的可视化画布。工作流由节点和连接组成，节点和连接控制顺序与流程。插入节点，然后配置并连接它们，以定义你希望 智能体 遵循的流程。

OpenAI 即将弃用 智能体 Builder。现有用户可在
  过渡期内继续使用，该产品计划于
  2026 年 11 月 30 日下线。ChatKit 仍可使用。请参阅 [弃用
  页面](https://developers.openai.com/api/docs/deprecations#2026-06-03-agent-builder) 了解当前的
  时间表。

在下方浏览所有可用节点。要了解更多信息，请阅读 [智能体 Builder 指南](https://developers.openai.com/api/docs/guides/agent-builder).

### 核心节点

从基础构件入手。所有工作流都具有起点和智能体节点。

![核心节点](https://cdn.openai.com/API/docs/images/core-nodes2.png)

#### Start

为你的工作流定义输入。对于聊天工作流中的用户输入，start 节点会做两件事：

- 将用户输入追加到对话历史中
- 暴露 `input_as_text` 以表示该输入的文本内容

所有聊天开始节点都包含 `input_as_text` 作为输入变量。你也可以添加状态变量。

#### 智能体

定义指令、工具和模型配置，或附加评估。

为每个智能体定义明确的范围。在我们的作业助手示例里，使用一个智能体改写用户的查询，以提升与知识库之间的针对性和相关性；再使用另一个智能体将查询分类为问答或事实查找；再使用一个智能体处理对应类型的问题。

像其他模型提示一样，添加模型行为指令和用户消息。若要将上一步的输出串联进来，可以将其作为上下文添加。

你可以按需添加任意数量的智能体节点。

#### 注意

留下关于你的工作流的注释和说明。与其他节点不同，备注节点不会 _执行_ 流程中的任何操作，它们只是为你和你的团队提供的有用说明。

### 工具节点

工具节点可让你为 智能体 配置工具和外部服务。你可以使用它们检索数据、监控滥用行为，并连接到外部服务。

![tool nodes](https://cdn.openai.com/API/docs/images/tool-nodes2.png)

#### 文件搜索

从你在 OpenAI 平台中创建的向量存储中检索数据。按向量存储 ID 进行搜索，并添加查询语句以指定模型应搜索的内容。你可以使用变量来引用 工作流 中先前节点的输出。

请参阅 [文件搜索 文档](https://developers.openai.com/api/docs/guides/tools-file-search) 以设置向量存储并查看支持的文件类型。

若要在 OpenAI 的托管存储之外进行搜索，请使用 [MCP](#mcp) 。

#### 护栏

为不良输入（例如个人身份信息（PII）、越狱、幻觉及其他滥用行为）设置输入监控。

护栏默认是“通过/不通过”模式，即检测上一个节点的输出，并由你定义后续处理。当护栏未通过时，建议结束工作流，或返回上一步并附上安全使用提醒。

#### MCP

调用第三方工具和服务。通过 OpenAI 连接器或第三方服务器进行连接，也可以添加你自己的服务器。在需要在其他应用（如 Gmail 或 Zapier）中读取或搜索数据的工作流中，MCP 连接非常有用。

在智能体构建器中浏览选项。要详细了解 MCP，请参阅 [MCP 文档](https://developers.openai.com/api/docs/guides/tools-connectors-mcp).

### 逻辑节点

![logic nodes](https://cdn.openai.com/API/docs/images/logic-nodes.png)

逻辑节点允许你编写自定义逻辑并定义控制流——例如，基于自定义条件进行循环，或在继续某个操作之前请求用户批准。

#### If/else

添加条件逻辑。使用 [通用表达式语言](https://cel.dev/) （CEL）创建自定义表达式，可用于定义如何处理已分类的输入。

例如，如果 智能体 将输入分类为问答，则将该查询路由到问答 智能体 以获得直接答案。如果是开放式查询，则路由到用于查找相关事实的 智能体。否则，结束 工作流。

#### 虽然

根据自定义条件循环。使用 [通用表达式语言](https://cel.dev/) (CEL) 创建自定义表达式，可用于检查某个条件是否仍然成立。

#### 人工审批

交由最终用户审批。适用于 智能体 起草内容、并在发出前需要人工审核的工作流。

例如，设想一个代表你发送邮件的 智能体 工作流。你会包含一个 智能体 节点来输出邮件组件，然后紧接一个人工审批节点。你可以将人工审批节点配置为询问“你希望我发送这封邮件吗？”，并在批准后继续执行连接到 Gmail 的 MCP 节点。

### 数据节点

数据节点可用于在 工作流 中定义和操作数据。可以重新调整输出格式，或定义供整个 工作流 使用的全局变量。

![数据节点](https://cdn.openai.com/API/docs/images/data-nodes.png)

#### Transform

对输出进行整形（例如，对象 → 数组）。可用于强制类型以遵循你的 schema，或将输出整形为 智能体 可读取和理解的输入。

#### 设置状态

定义可在整个 工作流 中使用的全局变量。当一个 智能体 接收输入并输出你希望在 工作流 其它地方使用的新内容时，全局变量非常有用。你可以将该输出定义为新的全局变量。
