> 浏览 OpenAI API 上提供的模型。

如果你不确定从哪里开始，可以使用 [GPT-6 Astra](/api/docs/models/gpt-6-astra)，我们的旗舰模型，适用于复杂推理和编码任务。选择 [GPT-5.6 Terra](/api/docs/models/gpt-5.6-terra) 以在智能和成本之间取得平衡，或者 [GPT-5.6 Luna](/api/docs/models/gpt-5.6-luna) 用于成本敏感、高吞吐量的工作负载。

所有最新的 OpenAI 模型都支持文本和图像输入、文本输出、多语言能力和视觉理解。模型可通过 [Responses API](/api/reference/resources/responses/methods/create) 以及我们的 [客户端 SDK](/api/docs/libraries).
