> 浏览 OpenAI API 上可用的模型。

如果你还不确定从何处入手，可以使用 [GPT-6 Astra](/api/docs/models/gpt-6-astra)，这是我们在复杂推理和编码方面的旗舰模型。选择 [GPT-6.1 Sol](/api/docs/models/gpt-6.1-sol) 以在智能与成本之间取得平衡，或选择 [GPT-6 Luna](/api/docs/models/gpt-6-luna) 用于成本敏感、高吞吐量工作负载。

所有最新的 OpenAI 模型都支持文本和图像输入、文本输出、多语言能力以及视觉理解。可通过 [Responses API](/api/reference/resources/responses/methods/create) 以及我们的 [客户端 SDK](/api/docs/libraries).

## 精选模型

- [GPT-6 Astra](/api/docs/models/gpt-6-astra.md)：从复杂推理和编码任务开始。
- [GPT-6.1 Sol](/api/docs/models/gpt-6.1-sol.md)：兼顾智能与成本。
- [GPT-6 Luna](/api/docs/models/gpt-6-luna.md)：针对成本敏感型海量任务进行优化。
