# 模型

> 完整的文档索引，请参阅 [llms.txt](/llms.txt)。文档页面的 Markdown 版本可通过在页面 URL 后追加 `.md` 获得。

> 探索 OpenAI API 上可用的模型。

如果你不确定从哪里开始，请使用 [GPT-5.6 Sol](/api/docs/models/gpt-5.6-sol)，这是我们用于复杂推理和编码的旗舰模型。选择 [GPT-5.6 Terra](/api/docs/models/gpt-5.6-terra) 以平衡智能和成本，或 [GPT-5.6 Luna](/api/docs/models/gpt-5.6-luna) 用于对成本敏感、高容量的工作负载。

所有最新的OpenAI模型都支持文本和图像输入、文本输出、多语言功能以及视觉。这些模型可通过 [Responses API](/api/reference/resources/responses/methods/create) 以及我们的 [Client SDKs](/api/docs/libraries).

## 推荐模型

- [GPT-5.6 Sol](/api/docs/models/gpt-5.6-sol.md)：从这里开始，适用于复杂推理和编码。
- [GPT-5.6 Terra](/api/docs/models/gpt-5.6-terra.md)：在智能和成本之间取得平衡。
- [GPT-5.6 Luna](/api/docs/models/gpt-5.6-luna.md)：优化成本敏感型、高容量工作负载。
