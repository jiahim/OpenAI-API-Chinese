> 探索 OpenAI API 上可用的模型。

如果你不确定从哪里开始，请使用 [GPT-6 Astra](/api/docs/models/gpt-6-astra)，这是我们用于复杂推理与编码的旗舰模型。选择 [GPT-5.6 Terra](/api/docs/models/gpt-5.6-terra) 以兼顾智能与成本，或选择 [GPT-5.6 Luna](/api/docs/models/gpt-5.6-luna) 用于对成本敏感、海量调用的工作负载。

所有最新的 OpenAI 模型都支持文本和图像输入、文本输出、多语言能力和视觉理解。你可以通过 [Responses API](/api/reference/resources/responses/methods/create) 以及我们的 [Client SDKs](/api/docs/libraries).
