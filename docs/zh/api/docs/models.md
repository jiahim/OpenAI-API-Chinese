> 完整文档索引请参阅 [llms.txt](/llms.txt)。在页面 URL 末尾添加 `.md` 即可获取 Markdown 版本的文档页面。

> 浏览 OpenAI API 上可用的模型。

如果不确定从哪里开始，可以使用 [GPT-6 Astra](/api/docs/models/gpt-6-astra)，我们的旗舰模型，专为复杂推理和编码设计。选择 [GPT-5.6 Terra](/api/docs/models/gpt-5.6-terra) 以平衡智能与成本，或者 [GPT-5.6 Luna](/api/docs/models/gpt-5.6-luna) 用于对成本敏感的高吞吐量工作负载。

所有最新的 OpenAI 模型都支持文本和图像输入、文本输出、多语言能力和视觉功能。模型可通过 [Responses API](/api/reference/resources/responses/methods/create) 和我们的 [客户端 SDK](/api/docs/libraries).

## Featured models

- [GPT-6 Astra](/api/docs/models/gpt-6-astra.md)：从这里开始处理复杂推理和编码。
- [GPT-5.6 Terra](/api/docs/models/gpt-5.6-terra.md)：兼顾智能与成本。
- [GPT-5.6 Luna](/api/docs/models/gpt-5.6-luna.md)：针对成本敏感的高负载场景进行优化。
