# 模型

> 有关完整的文档索引，请参阅 [llms.txt](/llms.txt)。通过在页面 URL 后追加 `.md` 可获得文档页面的 Markdown 版本。

> 浏览 OpenAI API 上可用的模型。

如果你不确定从哪里开始，请使用 [GPT-5.6 Sol](/api/docs/models/gpt-5.6-sol)，这是我们用于复杂推理和编码的旗舰模型。选择 [GPT-5.6 Terra](/api/docs/models/gpt-5.6-terra) 以平衡智能和成本，或 [GPT-5.6 Luna](/api/docs/models/gpt-5.6-luna) 用于对成本敏感、高吞吐量的工作负载。

所有最新的 OpenAI 模型都支持文本和图像输入、文本输出、多语言能力和视觉功能。模型可通过 [Responses API](/api/reference/resources/responses/methods/create) 和我们的 [Client SDKs](/api/docs/libraries).

## 推荐模型

- [GPT-5.6 Sol](/api/docs/models/gpt-5.6-sol.md)：从这里开始，适用于复杂推理和编码。
- [GPT-5.6 Terra](/api/docs/models/gpt-5.6-terra.md)：平衡智能与成本。
- [GPT-5.6 Luna](/api/docs/models/gpt-5.6-luna.md)：优化成本敏感、高吞吐量的工作负载。
